# LX04 PC Bridge

给小爱音箱触屏版 **LX04** 用的麦克风 + 扬声器桥接：音箱里跑一个很小的 APK（小于 400KB），用 **USB 数据线**连到 Windows 电脑。电脑上位机把音箱麦克风当成输入，把电脑正在播放的声音送到音箱喇叭，音箱 800×480 屏幕当状态显示器。

## 它做什么

- 音箱采集双麦阵列里的麦克风，把 PCM 音频经 USB（ADB 隧道）送给电脑
- 电脑上位机把麦克风灌进 [VB-CABLE](https://vb-audio.com/Cable/)，其它软件把 `CABLE Output` 选成麦克风
- 电脑正在播放的声音经第二根虚拟线 [Hi-Fi Cable](https://vb-audio.com/Cable/) 环回，再送到音箱喇叭
- 音箱屏幕显示：USB 状态、右上角日期和时间（系统设置里日期/时/分/秒可分别开关）、电脑资源占用、麦克风/扬声器可分别静音；从屏幕右侧向左滑出菜单，可进「系统设置」切换深色/浅色，与上位机「浅色」开关同步；系统设置里还可选监视页背景（默认纯色，或最多 3 张从上位机「上传背景」发来的图片）并调节卡片/按钮不透明度；也可在菜单里选「屏幕镜像」或「状态监视」；上位机也可切换浅色/深色并预览 800×480 样式（每个格子可分别选大字、多条小字、改标题、颜色和字号）；音箱上长按某一栏目也能编辑，与电脑完全同步；字不会画出格子；未连接时音箱上可点「重置样式」；上位机「系统旋转」可锁定整机正向或倒转（音箱没有陀螺仪，不会自动转；「吊装」仍只倒转桥接 HUD）；「后台运行」关掉桥接画面，音频仍走后台，屏幕还给小爱原界面
- 连接后屏幕同时显示电脑 CPU / GPU 温度和使用率、内存、所选磁盘占用、网速（上位机可关、可选监测哪块盘）
- 右侧菜单的「屏幕镜像」把电脑画面投到音箱，「状态监视」切回占用页；上位机「同步屏幕」可选哪一块显示器，并可把镜像码率调到「高清 / 最高」以提高画质
- 上位机「同步系统弹窗」打开后，Windows 原生通知的标题、正文和按钮会显示在音箱上（不是截图）；点按钮即点电脑上的系统通知，点空白处关闭

官方固件的 Micro USB **默认不能装第三方 APK**，也常被写成“不支持数据传输”。要用本项目，音箱需要已经能装普通 APK（社区官改 / 刷成 X04G / Lineage 等），并且使用 **能传数据的 Micro USB 线**（纯充电线不行）。

## 目录

| 路径 | 说明 |
|------|------|
| `app/` | LX04 上的 Android 8.1+ APK，无 AndroidX、无 Play 服务，体积按几 MB 设计 |
| `host/` | Windows 上位机（Python） |
| `protocol.md` | USB 上的 TCP 帧格式 |

默认端口：`17890`（音频/音量/状态），镜像另走 `17891`，系统弹窗另走 `17892`。上位机执行 `adb forward` 这三路后分别连接，不依赖 Wi-Fi。


## 硬件与系统

| 项目 | LX04 |
|------|------|
| 芯片 | MT8167，约 1GB 内存 |
| 屏幕 | 3.97 寸，800×480，横屏 |
| 麦克风 | 顶部双麦 |
| 接口 | Micro USB |
| 系统 | 原版偏 Android 8.1；国际版 X04G 为 Android 10。 |


## 体积

- APK安装后仅300KB左右
